# Silver Effects Beauty

A fantasy-themed portfolio website for a model/special effects artist with an interactive book page-turning effect.

## Features
- Interactive page-turning navigation
- Fantasy book aesthetic (olive green & gold theme)
- Portfolio gallery
- Contact form
- Responsive design
